# HoldUp Pixel-Art Scene and Challenge Asset Manifest

Provenance, license, and file inventory for all pixel-art sprites vendored under `web/public/blindfold/sprites/` for the HoldUp **Blindfold Challenge** and **Spot the Danger** interactive pharmacy and home scene.

## Compliance and Size Summary

- **License policy:** **100% CC0 1.0 Universal (Public Domain Dedication)** across all 11 source packs (`https://creativecommons.org/publicdomain/zero/1.0/`). Zero CC-BY or CC-BY-SA obligations, zero paid or ripped sprites, and zero commercial-game look-alike tilesets.
- **Voluntary on-page credit:** **Kenney Vleugels (Kenney.nl)** and **Kipperfalcon (OpenGameArt.org)**.
- **Vendored PNG count:** **95 lossless RGBA PNG files** in `web/public/blindfold/sprites/` (byte-for-byte unmodified from upstream CC0 archives).
- **Total vendored PNG size:** **`120,641 bytes` (`117.81 KiB` / `0.115 MiB`)**, well under the `300 KB` target and `1.2 MB` cap.
- **Native pixel grid:** Cohesive `16x16` world, character, and prompt grid (`18x18` standalone HUD hearts/packages, `48x48` 9-slice UI panels, `64x64` medical icon sheet), rendered with integer `image-rendering: pixelated` scaling.
