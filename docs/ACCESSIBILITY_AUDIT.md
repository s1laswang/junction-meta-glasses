# HoldUp Accessibility Audit, WCAG 2.2 AA/AAA Conformance & Screen-Reader Guide (`docs/ACCESSIBILITY_AUDIT.md`)

HoldUp is built **screen-reader-first and multimodal-by-default** across Meta Ray-Ban Gen 2 open-ear audio, Meta Ray-Ban Display (`600x600` additive waveguide HUD + Neural Band sEMG gestures), the React 19 companion PWA, and the native Android Kotlin DAT Bridge (`BridgeScreen.kt` with Android TalkBack `LiveRegionMode` and `en`/`fi`/`sv` resources). Every contrast ratio, pixel/dp touch target, acoustic earcon, keyboard shortcut, ARIA/Compose live-region contract, component SSR landmark, and open-ear spoken verdict rule documented below is enforced by automated tests and real-model evaluations (`web/test/wcagContrastTokens.test.ts`, `web/test/contrast.test.ts`, `web/test/allComponentsA11yAudit.test.ts`, `web/test/a11y.test.ts`, `web/test/components-a11y.test.ts`, `web/test/frameReadinessMeter.test.ts`, `web/test/emergencyMedCard.test.ts`, `web/test/earcons.test.ts`, `web/test/shortcutsModal.test.ts`, `web/test/i18n.test.ts`, `server/test/android-a11y-parity.test.ts`, `server/test/android-i18n-strings.test.ts`, and `eval/spoken_verdict_clarity_results.json`).

## 3. Acoustic Earcons, Haptics & Keyboard/Gesture Reference

| `camera_off` | `[659.25, 440]` *(E5 -> A4 falling fifth)* | `75 ms` | `sine` | `0.12` | `[20, 35, 20]` | Confirmation that camera stopped (manual or `45 s` idle shutoff) |

### 3.2 Modifier-Free Keyboard & Neural Band Bindings (`web/src/a11y/shortcuts.ts` & `ShortcutsModal.tsx`)
- **`Space`**: Toggle active live label check ON/OFF (`toggle_check`)
- **`S`**: Capture and verify a single frame via HTTP Snapshot mode (`snapshot_verify`)
- **`B`**: Scan medication barcode locally offline against `localStorage` (`offline_barcode`)
- **`L`**: Log taken dose for a verified `match` (`log_dose`)
- **`R`**: Repeat the last spoken verdict or coaching cue (`repeat`)
- **`T`**: Cycle visual theme (`dark` -> `light` -> `high-contrast`, `cycle_theme`)
- **`P`**: Open Consent, Privacy & Local Data Controls (`open_privacy`)
- **Meta Neural Band / Ray-Ban Display**: Thumb swipe `ArrowLeft`/`ArrowRight` moves focus along the 1D `/hud` action strip (`Repeat` default index `0`, `Log Dose` shown only on unlogged `match`, `Dismiss`); index pinch `Enter` activates (`150 ms` debounce); system Back pops the 2-entry history state back to `#000000` transparent standby (`docs/HUD_SPEC.md`).

### 3.3 Native Android TalkBack Localization & Jetpack Compose Semantics (`android-dat/`)
- **Trilingual TalkBack Resource Parity (`values`, `values-fi`, `values-sv`)**: `android-dat/app/src/main/res/values/strings.xml` (English default), `values-fi/strings.xml` (Finnish), and `values-sv/strings.xml` (Swedish) define `19` UTF-8 string resources (`app_name`, `4` foreground streaming notification strings, and `14` `cd_*` TalkBack content descriptions) with `100%` key and `%1$s..%4$s` positional placeholder parity enforced by `server/test/android-i18n-strings.test.ts` and `server/test/android-res-security.test.ts`.
- **Jetpack Compose Live Regions & `56dp` Touch Targets (`BridgeScreen.kt`)**:
  - **`LiveRegionMode.Polite`**: Announces the active `CAMERA ON - CAPTURE LED ACTIVE` privacy card (`R.string.cd_streaming_active`) whenever glasses streaming starts, plus real-time glasses device, worn/doffed, battery, and stream state transitions (`R.string.cd_glasses_status`) via `semantics(mergeDescendants = true)`.
  - **`LiveRegionMode.Assertive`**: Interrupts immediately on bridge, SDK, or HTTP ingest errors (`R.string.cd_error_alert`).
  - **Semantic Headings & `>= 56dp` Controls**: Section headers declare `Modifier.semantics { heading() }`, `StatusRow` merges label/value pairs via `R.string.cd_status_row`, and every `OutlinedTextField`, `Button`, and `OutlinedButton` (`Server URL`, `Session Code`, `Save Endpoint`, `Forget Saved Server`, `Connect Glasses`, `Start Streaming`, `Stop Streaming`, `Disconnect`, `Update Glasses Firmware`, `Update Glasses DAT App`) enforces `Modifier.heightIn(min = 56.dp)` with localized `contentDescription`.
