## Post-Production Assembly, `-16 LUFS` Loudness & WebVTT Mux (`/tmp` Only)

Never write `.mp4` renders into the repo workspace; assemble, normalize to `-16 LUFS` (`loudnorm=I=-16:TP=-1.5:LRA=11`), and mux `docs/video-captions.vtt` exclusively under `/tmp/`:

```bash
ffmpeg -y -ss 00:00:00 -to 00:00:15 -i docs/img/hw/H4-live-check-master.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -ar 48000 -ac 2 /tmp/holdup-beat1.mp4
ffmpeg -y -ss 00:00:00 -to 00:00:15 -i docs/img/hw/H1-camera-access.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -ar 48000 -ac 2 /tmp/holdup-beat2.mp4
ffmpeg -y -ss 00:00:10 -to 00:00:40 -i docs/img/hw/H4-live-check-master.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -ar 48000 -ac 2 /tmp/holdup-beat3.mp4
ffmpeg -y -ss 00:00:00 -to 00:00:20 -i docs/img/hw/H6-safety-ibuprofen-unsure.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -ar 48000 -ac 2 /tmp/holdup-beat4.mp4
ffmpeg -y -ss 00:01:15 -to 00:01:35 -i docs/img/hw/H4-live-check-master.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -ar 48000 -ac 2 /tmp/holdup-beat5.mp4
ffmpeg -y -loop 1 -t 20 -i docs/img/eval_model_compare.png -f lavfi -t 20 -i anullsrc=channel_layout=stereo:sample_rate=48000 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=60" -c:v libx264 -preset fast -crf 20 -c:a aac -shortest /tmp/holdup-beat6.mp4
printf "file '/tmp/holdup-beat1.mp4'\nfile '/tmp/holdup-beat2.mp4'\nfile '/tmp/holdup-beat3.mp4'\nfile '/tmp/holdup-beat4.mp4'\nfile '/tmp/holdup-beat5.mp4'\nfile '/tmp/holdup-beat6.mp4'\n" > /tmp/holdup-concat.txt
ffmpeg -y -f concat -safe 0 -i /tmp/holdup-concat.txt -c copy /tmp/holdup-stitched.mp4
ffmpeg -y -i /tmp/holdup-stitched.mp4 -i docs/video-captions.vtt -af "loudnorm=I=-16:TP=-1.5:LRA=11" -c:v libx264 -preset medium -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -c:s mov_text -metadata:s:s:0 language=eng -movflags +faststart /tmp/holdup-demo-final.mp4
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 /tmp/holdup-demo-final.mp4
```
